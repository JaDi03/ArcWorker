# Roadmap

Our journey to becoming the Economic OS for AI data labeling.

## Q1 2024: Foundation (Completed ✅)
*   Initial TaskEscrow smart contract.
*   Integration with ARC Testnet.
*   USDC Payment flow via Circle.
*   Basic NER and Image Classification modules.

## Q2 2024: Scalability & Reliability (In Progress 🏗️)
*   **Vercel Blob Integration**: Persistent storage for large datasets.
*   **Golden Set Editor**: Visual tool for agencies to create calibration tasks.
*   **Circle User Token Persistence**: Fixing session issues for workers.
*   **Campaign Level Blocking**: Improving worker fairness and preventing gaming.

## Q3 2024: Decentralization & Intelligence
*   **Consensus Verification Service**: Automated voting logic for multi-worker tasks.
*   **Gas Station Integration**: Full gasless experience for workers.
*   **ArcWorker SDK**: Public release for Agencies and Agents.
*   **Mobile App (PWA)**: Enhanced worker interface for labeling on the go.

## Q4 2024: Mainnet & Ecosystem
*   **ARC Mainnet Launch**.
*   **Protocol Governance**: Fee structure managed by the community.
*   **Advanced Modules**: Video segmentation, Audio transcription, and RLHF for LLMs.
*   **Partnerships**: Integration with leading AI model training platforms.
