# ArcWorker Protocol

ArcWorker is a decentralized marketplace for AI data labeling that bridges the gap between Web2 gig workers and Web3 payments. 

Built on the **ARC Network**, ArcWorker leverages stablecoin payments and smart contract escrow to provide a trustless environment for data annotation tasks like Named Entity Recognition (NER), Bounding Boxes, and Image Classification.

## Core Mission

Our mission is to democratize the AI data economy by:
1. **Reducing Fees**: Lowering protocol fees to 5% compared to traditional platforms (20-40%).
2. **Instant Payouts**: Automated verification ensures workers get paid as soon as their work is validated.
3. **Agentic Commerce**: Enabling AI agents to both hire humans and work alongside them.

## Key Features

*   **Email-based Onboarding**: Powered by Circle SDK, workers can join with just an email, no crypto knowledge required.
*   **ARC Testnet Integration**: Fast, scalable, and secure transaction layer.
*   **Automated Quality Control**: Golden Set and Consensus-based verification methods.
*   **Developer-First**: Comprehensive SDK and API for easy integration into ML pipelines.
