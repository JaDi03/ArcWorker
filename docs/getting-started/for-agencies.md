# Getting Started for Agencies

Agencies are organizations that need data labeled for machine learning models.

## 1. Registration
1.  Enter the dashboard via the admin link or contact our team for Beta access.
2.  Complete your Agency registration.
3.  Fund your account with USDC (ARC Network).

## 2. Creating a Campaign
1.  Navigate to **"Create Campaign"**.
2.  Choose a module:
    *   **Computer Vision**: Image labels, Bounding Boxes, Segmentation.
    *   **NLP**: Named Entity Recognition (NER), Sentiment Analysis.
3.  **Configure Task Details**:
    *   Upload your dataset (Text file, Image URLs, or CSV).
    *   Set the reward per task.
    *   Define labels or tags.
    *   Provide clear instructions and examples.

## 3. Choose Verification Strategy
*   **Golden Set**: Upload 5-10 "Gold Standard" examples with correct answers.
*   **Consensus**: Require 3+ workers to reach the same conclusion.
*   **Manual Review**: Approve every submission manually.

## 4. Launching
1.  Review the total budget (Reward x Task Count + 5% Fee).
2.  Confirm and pay.
3.  Your tasks go live in the Market instantly.

## 5. Exporting Data
Monitor progress in your **Agency Dashboard**. Once tasks are "Closed", you can export the results in JSON format or via the SDK.
