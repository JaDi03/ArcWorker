# ArcWorker Protocol
### Work for a minute, get paid in a second.

ArcWorker Protocol was created to solve the long-standing delays in worker payments. This is a decentralized marketplace for micro-tasking where liquidity meets labor, ensuring that if you do the work right now, you get paid right now. 

By bridging the gap between Web2 demand and Web3 financial efficiency, we've built a platform that removes the friction of high withdrawal minimums, predatory currency conversion fees, and multi-week payment delays.



## What makes us different?

- **Instant USDC Settlements**: We use the Arc Network for sub-second finality, meaning your earnings reach your wallet the moment the task is validated.
- **Gasless Experience**: We want everyone to be able to participate, which is why we used Circle's Programmable Wallets. You don't need to hold tokens to start working, just your email and a passion for getting things done.
- **Universal Reputation**: Every task completed builds a permanent, on-chain profile. This reputation belongs to the worker, not the platform, and can be used across any protocol in the ecosystem.
- **ArcWorker Engine (SDK)**: We aren't just building a dApp, we are building infrastructure. Our upcoming SDK will allow any developer to integrate our escrow and settlement logic into their own projects.
- **Programmable Trust**: Our Escrow Smart Contracts hold payments and release them only when proof of work is verified, protecting both agencies and workers.
- **Capital Efficiency**: We believe unspent campaign funds shouldn't just sit there, so they generate yield via USYC to help sustain the protocol's growth.

## Tech Stack

We've built this on top of the best technology available to ensure a seamless experience:
- **Blockchain**: Arc Network (EVM Compatible)
- **Identity & Wallets**: Circle Programmable Wallets (MPC)
- **Frontend**: Next.js with Tailwind CSS
- **Database**: Hybrid architecture supporting Vercel Postgres and local persistence.
